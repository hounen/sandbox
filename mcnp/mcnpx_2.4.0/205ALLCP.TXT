-------------------------------------------------------------------------------------------------------------------------
At this time, RSICC distributes 2 versions of MCNPX and their corresponding data packages. 
MCNPX2.3.0 users should request D00205ALLCP02 MCNPXDATA. 
MCNPX2.4.0 users should request D00205ALLCP03 MCNPXDATA.
The September 2002 D00205ALLCP03 MCNPXDATA release includes all files in the previous 
D00205ALLCP02 plus the EL03 electron data library. EL03 requires new functionality in MCNP4C 
or MCNPX 2.4.0. EL03 cannot be used with MCNP4B, MCNPX2.3.0 or earlier versions.
The D00205ALLCP03 MCNPXDATA "tapelist" is displayed below.

*****************************************************************************

 The cross sections are for use with CCC-715/MCNPX 2.4.0.
 This package was created by adding EL03 to D00205ALLCP02.

 These ASCII data are distributed on CD in a GNU compressed Unix tar file.
 Windows users should extract the files with WinZIP 8.0 or later.
 Alternately, Windows users may use GNU utilities for GZIP and TAR, but these
 utilities will require end-of-lines translation with a utility such as flip.

  See C715.PDF & D205.PDF in the DOC subdirectory for documentation. Various 
  additional reports on the MCNPXDATA files are included in the distribution 
  tar file and will be expanded to mcnpxdata/DOC on your computer.

 On unix or linux systems:
 Assume your CD-ROM drive is called "cdrom" and position to the parent
 directory on your hard disk to which you will extract files from the CD.

 gzip -dc /cdrom/D205TAR3.TGZ | tar xvf -

********************************************************************************
An "mcnpxdata" subdirectory will be created under the present working directory 
and will include the files listed below. The ASCII files require approximately 
1.2 GByte of disk space. MAKXS is distributed in the mcnpx code package and
can be used to convert them to binary files which will be smaller. 

Review the Readme* files in the DOC subdirectory for descriptions of libraries.
