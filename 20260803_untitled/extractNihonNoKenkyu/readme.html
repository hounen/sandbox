extractNihonNoKenkyu 使い方

概要

このプログラムは、KAKEN と AMED の研究プロジェクト情報を抽出し、Excel 形式で出力するツールです。

実行エントリーポイントは code/main.py で、設定は settings/input.ini から読み込みます。

準備

  • 作業ディレクトリ: extractNihonNoKenkyu
  • 設定ファイル: settings/input.ini
  • 検索対象: settings/extract_kenkyu_kikan/kaken.yaml と settings/extract_kenkyu_kikan/amed.yaml
  • 出力先: output/。実行時に output/nihon_no_kenkyu_YYYYMMDDhhmm 形式で保存されます。

設定ファイル

[CROSS_SEARCH] <= 全事業に適用する共通の検索条件を設定するセクションです。
KENKYU_KIKAN_FROM=2023 <= 抽出対象の開始年度を指定します。2023の場合、2023/4/1以降に開始されるプロジェクトが抽出されます。
KENKYU_YOSAN_FROM=500 <= 抽出する予算の下限（万円）です。
    
[KAKEN_SWITCH]
KENKYU_KIKAN_SYNC=true <= trueの場合、抽出前にKAKENデータベースから研究機関リストを再取得するか確認します。
EXTRACTION=true <= trueの場合、KAKENデータベースからプロジェクトデータを抽出するようになります。
    
[AMED_SWITCH]
KENKYU_KIKAN_SYNC=true <= trueの場合、抽出前にAMEDデータベースから研究機関リストを再取得するか確認します。
EXTRACTION=true <= trueの場合、AMEDデータベースからプロジェクトデータを抽出するようになります。
    
[KAKEN_SOURCE] <= KAKENデータベースに登録されている研究機関リストの取得先URLです。
KENKYU_KIKAN_URL=https://www-kaken.jsps.go.jp/kaken1/kikanList.do
    
[CINII_OPENSEARCH]
URL=https://kaken.nii.ac.jp/opensearch/ <= KAKENプロジェクトデータの取得先URLです。
APPID=8if8E9qcvGLiwX6YrbW5 <= 取得時に使用するキー情報です。
USE_CACHE=True <= 一度取得したデータをローカルPCに一時保存するかどうか設定できます(設定すると再抽出時の実行時間が短縮できます)
    
[KAKEN_OPTION]
RESULTS_PER_PAGE=500 <= KAKENデータベースから1度に取り出すプロジェクトの上限数です(基本、変更することはありません)
    
[KAKEN_SEARCH]
KENKYU_KIKAN_FILE=settings/extract_kenkyu_kikan/kaken.yaml <= KAKENデータベースから取得した(検索用としても使う)研究機関リストの保存先ファイルのパスです。
    
[AMED_SOURCE]
URL=https://grants.jst.go.jp/search/ <= AMEDプロジェクトデータの取得先URLです。
    
[AMED_OPTION]
RESULTS_PER_PAGE=500 <= AMEDデータベースから1度に取り出すプロジェクトの上限数です(基本、変更することはありません)
    
[AMED_SEARCH]
KENKYU_KIKAN_FILE=settings/extract_kenkyu_kikan/amed.yaml <= AMEDデータベースから取得した(検索用としても使う)研究機関リストの保存先ファイルのパスです。
KENKYU_KIKAN_CONDITION=1 <= プロジェクト期間の抽出条件の詳細設定です(1の場合、特定の年度以降に開始されるプロジェクトに限定されます)
※統一感を優先して、全事業で設定年度以降に開始されるプロジェクトを抽出するように設定しています(過去に研究開始した進行中のプロジェクトは抽出されないようになっています)
    
[OPTION]
IDENTIFY_PREFECTURE=true <= 研究機関名から所在地の都道府県を特定するか設定します(trueの場合、GoogleMapから所在地の緯度・経度を取得して、特定を試みます、外国や同名の法人、複数拠点を持つ法人は特定できません)
OUTPUT_PLACE_PATH=./output <= 抽出結果を出力するベースフォルダを指定します
MAX_WAIT_TIME=0.1 <= 管理、デバック用です
SLEEP_TIME=5 <= 管理、デバック用です
PAGE_RETRY=3 <= 管理、デバック用です

実行方法

  1. 設定を確認する
    settings/input.ini を開き、検索 URL、検索条件、出力先を確認します。
  2. 検索対象を編集する
    settings/extract_kenkyu_kikan/kaken.yaml と settings/extract_kenkyu_kikan/amed.yaml を必要に応じて編集します(メモ帳で編集する場合は、既定のプログラムをメモ帳に設定します。検索条件から除外したい法人の行をコメントアウト(行頭に#を記入、または検索したい法人の行だけ残して他は削除)して使用します。保存のし忘れに注意してください。)
  3. 実行する
    local_online_run_main.bat でローカル実行、または sharefolder_online_run_main.bat で共有フォルダ実行できます。(いずれもダブルクリックです)
  4. パス変更時の再構築
    実行場所を移動した場合は local_online_venv_recreate.bat または sharefolder_offline_venv_recreate.bat を実行してください(※1時間以上かかります)。

出力結果

抽出結果は output/ 以下にサブフォルダとして保存されます。ファイル名は nihon_no_kenkyu_YYYYMMDDhhmm 形式です。

各研究機関ごとに Excel ファイルが生成されます。

注意事項

  • 実行時間の目安、KAKENとAMEDで研究機関リストを更新して、2023年以降開始で予算500万円以上のプロジェクトを都道府県判別ありで抽出する場合、4時間ほどかかります。
  • AMEDはプロジェクトが存在しても予算が未確定な場合が多いので、予算条件によらず未確定の場合は抽出するようにしています。
  • KAKENやAMEDなどの各データベースの取得先が休止中やシステム改修などにより変更が生じた場合はプログラムは動作しなくなります(変更に応じてSYNCオプションなどをfalseにして処理をスキップさせてください)。
  • ネットワークが遅い状態だとタイムアウトエラーが発生しやすくなります。
  • 共有フォルダ上から実行する場合、ネットワークドライブレターはR:を使用しますので、既にR:が使用されている場合は、R:を切断するか、R:が使用できない場合、他の端末で実行してください。
  • 同一の研究機関でもKAKENとAMEDで登録されている研究機関名が若干違う場合が多いので、特定の研究機関のみ検索する場合は対象とする法人名は注意して選択してください

トラブルシューティング

  • 出力ファイルが見つからない: output/ フォルダと生成されたサブフォルダを確認してください。
  • 起動に失敗する 以前動作させたPC環境のEdgeブラウザとバージョンと異なる場合、起動に失敗することがあります。その場合は、もう一度実行させてください。
  • 研究機関リストは毎度更新されることはないので基本更新させたくない: KAKEN_SWITCH / AMED_SWITCH の KENKYU_KIKAN_SYNC を false に設定してください。
  • 実行パスが変わった: local_online_venv_recreate.bat または sharefolder_offline_venv_recreate.bat を実行してください。
